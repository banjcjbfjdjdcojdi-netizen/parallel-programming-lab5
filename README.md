# Лабораторная работа №5 (Program 1)

Параллельная генерация фрактала Мандельброта с использованием `std::thread` (по материалам Stanford CS149).

## Состав проекта
- `prog1_mandelbrot_threads/` — исходный код программы.
- `common/` — вспомогательные файлы.
- `run_benchmarks.py` — скрипт для сбора статистики.
- `plot_speedup.py` — скрипт для построения графиков.
- `results/` — CSV с данными и графики.
- **`REPORT.md` — полный текст отчета.**
